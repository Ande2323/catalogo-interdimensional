Acceso de editor

Necesitas un token de GitHub con permiso de escritura sobre este repositorio. Se guarda solo en este navegador y nunca se sube a ningún sitio.

Si el repositorio es tuyo
  1. Crear token fino
  2. Repository access: Only select repositories → este repo
  3. Permissions → Repository: Contents: Read and write
Si colaboras en el repositorio de otra persona
  1. Crear token clásico (el fino no sirve en este caso)
  2. Marca solo la casilla public_repo
  3. No marques repo: daría acceso también a tus repositorios privados
